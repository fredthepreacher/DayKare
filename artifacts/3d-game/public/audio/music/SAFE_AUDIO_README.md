# DayKare production-safe music loops

These four loops are non-destructive derivatives of the owner-supplied `DayKare_Music_Time_Daycare_Life_Pack.zip` masters.

The supplied authored cues were transcribed before release. Several contained explicit or age-inappropriate lyrics, so those vocal sections are intentionally excluded from the shipped game. These loops use verified vocal-free spans, with short fades added for clean browser looping:

- `daycare-calm-loop.mp3` — `best_wishes_full.mp3`, 24.7–51.7 seconds
- `garden-sunshine-loop.mp3` — `ferragamo_full.mp3`, 214.2–235.7 seconds
- `juice-club-bounce-loop.mp3` — `change_some_draft_3_full.mp3`, 136–157 seconds
- `storybook-dream-loop.mp3` — `best_wishes_full.mp3`, 0–10.1 seconds

The original source archives were not modified or copied into the web build.

The six `music_*_alt_01.ogg` files are additive, normalized segments from the
owner-supplied `DayKare_New_Audio_Variation_Pack.zip`. Their contextual mapping
is documented in `public/audio/variation_manifest.json`; the four established
safe loops above remain available in every applicable rotation.
